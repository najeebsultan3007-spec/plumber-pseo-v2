# Emergency Plumbing pSEO Template (Next.js 14, App Router)

    npm install
    npm run dev        # http://localhost:3000/plumbing/ohio/zanesville
    npm run build

- Phone number: `lib/config.ts` (single source; used by every CTA, bar, footer link and schema)
- Add cities: `data/cities.ts`; each row builds a static page and a sitemap entry
- Set `NEXT_PUBLIC_SITE_URL` to your production domain for canonicals, sitemap and schema

Before launch: make sure the claims on the page (30-minute response, 4.9 rating, licensed
and insured, guarantee) are accurate and documented, and that your jurisdiction's
advertising and contractor-license disclosure rules are met.
